# AI Content Generator

A lightweight ChatGPT-like AI content generator that can create text for any prompt.

Built with vanilla HTML/CSS/JS and deployed on Netlify with serverless functions.

## Features
- Chat-style interface
- Generates stories, emails, code, poems, essays, and more
- Powered by Meta Llama 3.1 via OpenRouter (free tier)

## Setup
1. Get a free API key from [OpenRouter](https://openrouter.ai)
2. Set `OPENROUTER_API_KEY` as an environment variable in Netlify
3. Deploy to Netlify

## Local Development
```bash
npm install
npx netlify dev
```
